# 🕵️ SQL Murder Mystery

## Project Overview

A practical SQL investigation project using **PostgreSQL** to solve a fictional murder in SQL City.

I analyzed police records, witness statements, gym memberships, vehicle information, and concert attendance to identify the murderer.

## 🛠️ Tools & Skills

* PostgreSQL
* SQL
* JOINs
* Subqueries
* GROUP BY & HAVING
* Aggregate Functions
* Data Filtering & Analysis

## 🔎 Investigation

Using SQL queries, I progressively narrowed down the suspects by connecting evidence from multiple database tables.

### Final Suspect

**Miranda Priestly**

## 🎯 Key Learning

This project strengthened my ability to use SQL for **data investigation, problem-solving, and relational database analysis**.
